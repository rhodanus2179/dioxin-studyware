# ダイオキシン類関係・独立書籍制作ワークスペース

**仮題：公害防止管理者試験 ダイオキシン類関係 要点と演習**

このディレクトリは、公害防止管理者試験の「ダイオキシン類概論」「ダイオキシン類特論」に対応する**独立した短期学習書**の制作場所です。正式タイトルは未確定。従来の「超速マスター」は新書籍の名称に使用しません。

## 制作の方針

- Studywareから**知識ID・法令等の出典台帳・過去問の研究結果**を参照する。
- **本文・見出し・図解・演習問題・解説は書籍用に独立して制作する**。Studyware本文をそのまま取り込まない。
- 章→節→項→目で執筆し、節ごとに「要点まとめ→本文・図解→独自演習→全肢解説」を配置する。
- 目標は224頁（44学習単元の本編212頁＋付録12頁）。**初稿では内容の網羅性・正確性・説明の充実を優先し、1頁概ね900字という目安に合わせた分量・組版調整は全章初稿完成後の最終工程で行う**。対象外の共通科目「公害総論」は別企画とする。
- 著作権のある他社教材・公式問題文・図表の無断転載は行わない。
- 科学・法令・JIS・出典・権利の検証が済むまで未監修原稿を完成・出版承認済みと表示しない。
