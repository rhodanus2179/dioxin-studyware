# 執筆・編集方針

## 目標

「新・公害防止の技術と法規」のように制度・実務まで詳説する網羅的な講習用テキストではなく、「超速マスター」などの要点整理よりも一段丁寧に、試験で問われる知識の**意味とつながり**を説明する。

## 文章の原則

1. 専門用語の羅列から始めず、先に「なぜ必要な話なのか」を示す。
2. 一段落に中心概念を一つ。数字の前に役割と比較対象を説明する。
3. **原因 → 現象 → 影響 → 対策 → 測定**の順で論点間の関係を描く。
4. 試験に必要な説明を優先し、実務上の例外・歴史の枝葉はコラムに分離する。
5. 用語や数値を出す際は、適用範囲・単位・法令時点・情報源を明記する。
6. 親しみやすく書くが、あいまいさや不正確な断言を避ける。
7. 各節は「まず何が起きる？」「なぜ？」「だから何をする？」を軸にし、最後に確認問題と結びつける。

## 内容の検証

- 法令：e-Gov法令検索、環境省・告示等の一次資料を優先。
- 出題範囲・問題数：JEMAI公式資料を参照。
- 年ごとの統計：対象年度と公表日を分けて記載。
- 測定法：適用範囲・版・通知・JIS番号を明示。
- 公式過去問は参考資料として扱い、転載の可否を別途確認する。学習サイト内で公開する演習は原則オリジナル問題とする。
- 初稿段階の論点を「試験網羅済み」と表示しない。

## ステータス

- planned：章立てのみ作成。
- draft：初稿公開。検証・増補が必要。
- reviewed：内容確認済み。
- released：公開版の編集・検証が完了。

## 優先順位

序章（概念と歴史） → 基礎（性質・TEF/TEQ・生成・影響） → 制度と基準 → 大気・水質の対策 → 測定 → 過去問分析に基づく増補。

## 本文執筆前に採択する編集基準（2026-10-10提案）

- **法令・公的資料に基づく用語と解説の書き方**：[法令・公式資料の記述基準](editorial/legal-and-official-source-writing-policy.md) を参照。法律／政令／省令／告示／通知・公的解説／JIS／科学知見を区別し、根拠文書・条項・施行日・出典版を記す。法令の短い正確な表現を先に置き、平易な理解用説明を後に続ける。
- **図と詳細プレースホルダ**：[図版制作基準](editorial/figure-production-policy.md)と[19件の図版台帳](editorial/figure-backlog-v1.md)を参照。化学構造は検証済み分子情報とRDKit、フローはMermaid、工学装置は編集可能な模式SVG、グラフは公式元データと再現スクリプトを原則とする。
- 未制作の図に描画済みの状態を付けない。図なしでも本文だけで重要な定義・条件・結論を理解できるように執筆する。
- **資格・管理組織の根拠**である公害防止組織整備法と、**ダイオキシン類の環境規制**の根拠である特別措置法は別の法律であることを明示する。
- 正確な用語を省略しない：例えば「環境基準」は一般に環境基本法第16条に見られる目的を踏まえるが、**ダイオキシン類の基準の直接の法的根拠は特措法第7条**。環境省の「行政上の政策目標」という説明は行政解釈・制度説明として区別する。
