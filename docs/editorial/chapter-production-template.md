# 教材制作テンプレート・進捗基準（2026-10-12）

## 制作順序（当面）
1. **第4章 性質**：正式5節15項の原稿初稿作成、TEF・TEQ・蒸気圧・分配・環境動態の条件付き根拠を明記 → **今回の作業ブランチ**。
2. **第5章 汚染の発生機構**：現行短稿を正式5節に沿って拡張。前駆体経路とde novo、温度・銅等の触媒、排ガス・灰への移行の説明を整える。
3. **第6章 汚染による影響**：毒性機序、ヒト曝露、TDIと作用点。第4章のTEQ・生物蓄積と相互参照。
4. **序章・第1〜3・7章**：既存本文の目次整合→背景・排出統計・制度。対象時点と出典を保持。
5. **第8〜12章（特論）**：工程・施設別基準・測定。化学構造図・工程模式図・計算式を段階制作。
6. **最後に独立監修・公開準備**：全項・知識ID・過去問論点を点検し、P01〜P05と配信対象ファイルを確認。完成前でも本文執筆は続けるが、HOLDや正式公開判定は変更しない。

## 各節の本文テンプレート
- 節見出しは正式`X.Y`、項見出しは詳細目次`X.Y.Z`を維持。知識IDを項見出しに記載。
- 最初に「なぜこの概念を学ぶか」を述べ、定義・条件・因果・応用・誤解しやすい境界を**段落で説明**する。
- 具体的な数値では、**比較する物質・版・相・温度・単位・集成/実測/推算**を揃える。法令なら条項・施行日・媒体を揃える。
- 必要な図は台帳のIDで企画し、完成検証まで`planned`。レンダラ未対応の図トークンを本文に直接置かない。
- 各章末には、自分の言葉で答えられる理解確認と出典・未完了事項を記す。独自演習は原則別ファイルで草稿化。
- 外部リンクは公的・一次資料を優先し、Markdownで出典を示す。非公開Drive IDや公式過去問の再録を含めない。

## 完了判定（執筆、科学QA、公開を分離）
- `planned`：正式項と学習焦点が整理された段階。
- `draft`：本文が存在し、正式項に沿うが、記述・出典に未完了事項がある段階。
- `reviewed`：対象項について典拠の原文・版・条件・教育的説明を照合し、重要な問題に独立確認が済んだ段階。
- `released`：科学QAのみでなく、図・演習・権利・公開ファイル・端末表示を含む正式P01〜P05判定後、責任者が公開承認した段階。

**K（正答）、V（原題原本）、E（典拠）、Q（教育表現）は互いに独立**。教材本文の初稿を作っただけでは4軸を完了にしない。特に過去問のHOLDは本文と無関係に維持。新しい独自演習も、専用の承認状態なしに`data/questions.json`へ追加しない。
