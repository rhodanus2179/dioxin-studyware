# 法令・公式文書に基づく教材記述基準 v1（2026-10-10）

## 基本方針
**やさしい説明は、正確な制度的意味と法令用語を示した後に置く。** 説明のための比喩が法令の定義に取って代わることを禁止する。教材では「厳密さを省略する」のではなく、法令の要素を論理的にほどいて教える。

## 法令・公的資料の階層（混同しない）
1. **法律**（法律名・条・項・号・施行日）：目的・定義・義務・権限・規制枠組み。
2. **政令・省令**（条・別表・施行日）：委任された具体的対象・数値・条件・測定等。
3. **告示**（番号・改正日・適用日）：法律の根拠に基づく基準値や技術的細目など。告示内容の拘束力は根拠法令・内容ごとに判断。
4. **通知・行政解釈・運用文書**（発出機関・年月日）：制度趣旨・実務解釈。**法律の条文そのものと混同しない**。改廃・現行実務への適用は別途検証。
5. **指針・審議会答申・行政パンフレット・公式統計**：背景・施策・データの説明。「法的義務」との関係を一つずつ確認。
6. **JIS・技術文献**：試験・測定・装置・反応の具体的内容。JISの規格本文を法令がどう参照しているか、規格の版を明示。JISの本文・図の転載権限は別判断。
7. **学習用解説**：出典の要点を正確に言い換えた独自文。どの部分が法令由来でどの部分が編集上の比喩か識別できるようにする。

## 法令を教える段落の基本6要素
- **制度上の問い**：なぜ必要か。
- **法令上の位置付け**：根拠条・項・号＋厳密な定義／制度名。
- **適用対象・要件・例外**：誰が何を、どの媒体・施設・事業場について行うか。施行日・経過措置を区別。
- **やさしい意味づけ**：日常語で説明する。ただし義務語（義務・努力・できる・命令）は弱めたり強めたりしない。
- **他の制度との対比**：環境基準／排出基準／TDI、施設／事業場、法律／通知など。
- **試験上の着眼点と出典**：引っかけやすい概念・単位・数値と、出典の文書・条項・版。正確な条文の引用は必要最小限・出典明示。

## 重要例：「環境基準」
- **環境基本法第16条（一般的な環境基準）**：人の健康の保護および生活環境の保全のため、維持されることが望ましい基準を政府が定める。
- **ダイオキシン類対策特別措置法第7条（この教材の中心）**：大気・水質（水底の底質を含む）・土壌の汚染に係る環境上の条件について、**「人の健康を保護する上で維持されることが望ましい基準」**を政府が定める。
- **重要な法的根拠の違い**：ダイオキシン類の環境基準は、**環境基本法第16条の規定に直接基づくものではなく、特措法第7条に基づく**。環境基本法の説明に「生活環境の保全」を含めることと、特措法第7条の法文にそれを補って転記することを混同しない。
- **行政上の性格**：環境省は環境基準を行政上の政策目標と説明し、特措法の施行通知でも環境保全諸施策の共通行政目標と位置付ける。これは**通知・行政解説による性格の説明**であって、条文第7条の字句の引用ではない。
- **誤解しやすい点**：「環境基準を超えること」と「特定施設が排出基準に違反したこと」を同一視しない。基準の対象媒体・規制主体・測定場所・制度上の効果が異なる。
- **数値**は環境庁告示第68号（改正を含む）の媒体別規定を確認し、単位・大気/水質の年間平均・地域や土地の適用除外・土壌250pg-TEQ/gの追加調査上の位置付けまで含める。

### 推奨する本文表現例
**定義・根拠**：ダイオキシン類に係る環境基準は、ダイオキシン類対策特別措置法第7条に基づき、人の健康を保護する上で維持されることが望ましい環境上の基準として定められている。

**制度上の役割**：環境保全施策の共通の行政目標である。施設や事業場からの排出ガス・排出水に適用される排出基準とは異なる。

**理解の補助**：環境基準は「周囲の環境をどの状態に保ちたいか」、排出基準は「対象となる排出源にどの限度を求めるか」を考える目安。この言い換えは正式定義の代わりにせず、上の法令上の意味を必ず併記する。

## 用語の編集チェック
| 語 | 必ず保つ意味 | 避ける言い換え・誤り |
|---|---|---|
| 環境基準 | 根拠法、環境媒体、保護目的、行政目標 | 単なる「環境の基準」、全ての排出への直接の違反基準 |
| 大気排出基準／水質排出基準 | 法第8条と関連省令、対象施設・事業場と排出媒体 | 環境基準と混同、排出水の適用単位を曖昧にする |
| 特定施設 | 法第2条第2項と施行令別表の指定条件 | 設備名称だけで必ず対象と断定する |
| 水質基準適用事業場 | 特定施設と事業場排出水の法的関係 | 施設から出るすべての排水が一律に対象と断定する |
| 耐容一日摂取量（TDI） | 法第6条に基づく施策指標。具体値・政令委任を区別 | 一度超過しただけで直ちに健康被害、環境基準との直接換算 |
| ダイオキシン類（法的定義） | 法第2条のPCDF・PCDD・コプラナーPCBの用語 | 法律がDL-PCBなどの略称だけで規定していると書く |
| 届出・命令・測定 | 条文、義務主体、適用要件、期限を区別 | 「しなければならない」と「努める」を入れ替える |
| WHO-TEF、TEQ | TEFの版、法令適用版、測定対象、換算式 | WHO最新版が直ちに日本の法定適用版と断定する |
| JISに基づく測定 | JIS番号・発行年、法令上の引用先と測定媒体 | JIS一般論を法的義務そのもののように扱う |
| 発生機構の説明 | 科学的に確認された事実とモデル・仮説を区別 | 相関や反応候補を因果・唯一の発生経路として断定する |

## 各主張に紐付けるメタデータ（今後の本文レビュー単位）
`claim_id, item_id, claim_type（条文/政令/告示/通知/技術/統計/学習用説明）, proposition, source_id, law_article_or_table, effective_on, version, source_verified, editorial_review, exam_year_scope, notes`

- **原本で照合した事実**と、**登録済みの出典URLから推測した内容**を同じ`verified`として扱わない。
- 法令の条文は短く必要箇所を引用し、その後に独自の解説を置く。原文と要約を明確に区別。
- 年度別過去問の正誤を説明する際は、その年度の基準日・施行中の条文・当時の規格を確認。2026年現行法の数字で過去問を自動的に上書きしない。
- 「根拠文書の所在」「原文を照合」「文言を解釈」「原題選択肢で検証」は別々の進捗とする。
- 画像・表にも同じ原則を適用。図に法的条件・統計的な数値を書いた場合、その図内の表示も対象。
