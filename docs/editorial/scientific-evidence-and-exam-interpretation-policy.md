# 科学的データと国家試験の解説：出典の衝突を裁定する編集規則 v1

制定：2026-10-12。適用対象：ダイオキシン類概論・特論、特に物性・毒性・工程・計測・統計の**数値を伴う説明**。法令の優先順位や施行日の扱いは[法令・公式資料の記述基準](legal-and-official-source-writing-policy.md)を併用する。

## 基本原則

**試験で想定する正誤判断の説明と、科学的な普遍命題の証明は同じではない。** 試験の公式正答を勝手に訂正しない一方、出題の概括的記述を「すべての異性体・全温度に厳密に当てはまる物理法則」と誇張しない。

1. **参照の出発点は、出題時点の公式問題・解答と、採用された行政・技術資料。** 国内試験の説明では、環境省・e-Gov・JEMAIの適切な原典を先に探す。国際機関・査読論文を排除せず、相違が出たら条件を比較する。行政公表であるだけで「最も精度の高い直接実測」と認定してはいけない。
2. **資料の権威と、値の生成方法を二軸に分ける。** 環境省公表ハンドブックはその文書の公的原本だが、そこに引用される蒸気圧は他の論文の**分析値／推算値を集成した二次データ**になり得る。公的な「記載の確認」と、測定研究の「実験条件まで追試・精査」を別の証拠階層とする。
3. **比較条件を合わせる。** 物質群（PCDD/PCDF/Co-PCB）、同族体平均／個別異性体、DL-PCB／全PCB、固相／液相／過冷却液相、温度、蒸気圧の種類、実測／推算、単位（Pa、kPa、mmHg）、代表値の集約方法を一覧で管理する。条件が異なる値を一つの「典型値」に混ぜない。
4. **異なる数値が出ても両方を残す。** 旧資料を削除せず、出典・版・条件・測定法・数値の違い・何を支持するかを記録する。差の理由を特定できないなら「資料間の不一致」と記し、無理に一致したことにしない。
5. **設問と解説を分離する。** 公式正答をK（正答）、原題の下線や数値をV（視覚確認）、科学的根拠をE、受験者に誤解を与えない説明をQとして独立に判断する。K=合致やE=部分支持だけでQの最終承認、転載許可、公開可としない。
6. **P0の解除は対象論点に限る。** 出題の想定した代表値・正誤理由に公的な条件付き根拠が特定され、従来の矛盾が整理されれば「物性値典拠のP0」を解除できる。ただし当時のJEMAIテキスト・原題PDFの同一性、全主張の監修・著作権が未確認ならP1とHOLDを維持する。
7. **教材本文は『記憶する要点 → なぜそうなるか → 代表値と出典・条件 → 例外』の順。** 試験で必要な代表的桁は示すが、原著を全件レビューしていない場合は個別値を普遍法則として断定しない。

## 事例：R05ダイオキシン類概論 問10の蒸気圧

**誤りの選択肢は②（JEMAI公式正答）**。環境省2004年[『ダイオキシン類挙動モデルハンドブック』表8.3・8.4](https://www.env.go.jp/air/tech/kyodomoderuhandbookH16.pdf)と環境省2011年[土壌処理ガイドライン表1.3-2](https://www.env.go.jp/press/files/jp/17285.pdf)では25℃で、TeCDDs同族体平均 **1.9×10^-6 Pa**、TeCDFs同族体平均 **3.3×10^-6 Pa**、OCDD **1.1×10^-10 Pa**。前者とOCDDの比は**約1.7万倍＝約4桁差**であり、設問の約2桁は誤り。

同資料のCo-PCB異性体別値は #77 **6.0×10^-5 Pa**、#126 **3.9×10^-5 Pa**、#189 **1.7×10^-6 Pa**。#189値はForeman and Bidleman (1985)由来の**推算値**であり、実測値と書かない。一方、IARCの全PCB同族体の液相平均や、英国政府系データ集の#189の別値は対象条件が違う可能性があるため、上記の環境省値の「反証」として自動的に採用しない。これを「別出典の確認値」として保存する。

**教訓：** 最初は全PCBの同族体液相平均と個別DL-PCBを横並び比較したため、④⑤の試験上の典拠が不明瞭になった。環境省のCo-PCB**異性体別表**に遡ったことで、③～⑤の出題解釈を条件付きで支持できた。過去の監査本文を削除せず[第40パス](../research/quality-audit-pass40-vapor-pressure.md)に追記し、[第41パス](../research/quality-audit-pass41-vapor-reconciliation.md)を最新裁定とした。**3件の物性値P0はP1へ、公開HOLD175は維持**。

## 次回の実務手順（1主張につき記録）

| 項目 | 必須の記録 |
|---|---|
| 問題・主張 | 年度、科目、問・下線番号、公式正答、主張の種類 |
| 証拠と出典 | 出典ID、発行主体、資料名、年、ページ・表、URL、文献が引用する原著 |
| 科学・計測条件 | 異性体・同族体、温度、相・媒体、実測/推算、単位、数値換算 |
| 相違の裁定 | 一致点、不一致点、比較条件が等しいか、未解決点と対応優先度 |
| QAの四軸 | K/V/E/Qの判定を別々に明記し、現時点のHOLDを保存 |
| 次工程 | 原題公式同一性／JIS正本／原著／第三者校閲／著作権のどれが残るか |

### 推奨する説明の構造

> 試験では「高塩素化物ほど蒸気圧が低い」が基本。環境省の25℃代表値ではOCDDはTeCDDs平均値より約4桁低い。ただし、数値は対象の異性体・相・温度・実測か推算かで異なるため、すべての化合物について同じ倍率を保証するものではない。

## データ更新時の禁止事項

- 旧パスに残る「P0」「未解決」を無言で消して監査経緯を隠すこと（**履歴は維持し、最新裁定への案内を付ける**）。
- 現在のレビューキューと横断トリアージで異なる**現行**優先度を表示すること。
- 独立資料のURLがあるだけで「科学根拠検証済み」「正式JIS本文確認済み」と数えること。
- ユーザーの非公開Drive ID、公式過去問の紙面・図・本文の大量転載を公開GitHubに登録すること。
- PRの研究基盤マージを、175件HOLDや教材の公開承認と同義にすること。
