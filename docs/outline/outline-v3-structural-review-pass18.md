## 現行の過去問対応から誤読してはならないこと

- 知識マップは**212件すべてが63節のいずれかに配置済み**。しかし既存ID自体が項目の網羅性・妥当な粒度を保証するわけではない。
- 200設問を単一の節に暫定割当した現行索引では、**A05の47問すべてが12.3「前処理」**、**A01の37問中36問が8.3「排ガス処理と除去」**、**G01の27問中21問が1.5「届出・行政措置・測定」**に偏在している。この節別ヒストグラムは仮の機械的集約であり、出題分布や節の不足・過剰の科学的根拠に使わない。
- 現行の11.2への21知識ID集中（うちW01～W19の19施設号が含まれる）は、**施設区分の網羅リストの仮置き**がもたらしたもので、新目次の構成確定後に適切な節に再配置する必要がある。
- R03～R07の200問／1,000選択肢には理由草稿があるが、選択肢ごとの節・知識ID完全対応は未完了。各節に主設問の仮リンクが「0」でも省略不可。
