# 第26パス：初期の章分類不一致12問に対する主章・主節の裁定

2026-10-10。初期の設問索引と各年度レビューの不一致12件について、各問の主題・5選択肢の解説草稿を比較し、**12問すべてに教材上の主章・主節を指定**した。原題の紙面および図と一次資料の全件独立監修が完了したわけではない。

[個別12問の決定理由と留保](outline-v4-chapter-resolutions-pass26.csv)／[正式65節目次](outline-v3.md)。

## 裁定の原則
- **国家試験上の科目（概論/特論）**は元の試験識別子に保持し、**教材内の主章**とは独立させる。R04特論問13の臭素系TEF議論は、特論の問題でも教材では第4章（性質・TEF）を主に学ぶ。
- 施設「数・順位」を問う問題は法律上の届出義務よりも排出源実態の章を優先し、**施設「指定要件」**なら法規章、**設備の運転技術**なら対策章を優先する。
- 正しい主章が決まっても、選択肢に横断内容がある場合には副知識IDを付ける。問全体の単一主章を理由に、5選択肢の知識を同一にしない。
- 元の`outline-v3-chapter-discrepancies-pass19.csv`は履歴として保持。今回の`resolutions`を現在の裁定正本とする。
- **今回の章分担の編集上の不一致は0件**。ただし過去問選択肢の真偽、法令時点、出題原本等に未監査の箇所があるので、出題頻度の厳密な統計や検証済み解説を意味しない。

## 未解消の主張レベルの確認
特にR03-G-Q07の2001～02年度施設数、R04-G-Q11の蒸気圧、R04-A-Q13の臭素系TEFに関するWHO原文、R05-A-Q24のブランク条件は一次出典・規格版の照合が必要。これは**章割当の裁定**とは別の品質ゲート。
