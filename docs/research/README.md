# ダイオキシン類Studyware：調査・設計フェーズ

更新日：2026-10-09

**本文執筆より先に、知識体系を完成させる。**

## このフォルダの成果物

- `source-register.csv`：法令・環境省・WHO・JEMAI等の出典台帳。本文の掲載可否・最新版確認とは別。
- `legal-framework.md`：政策→法→政令→規則→告示→技術指針の階層と横断論点。
- `knowledge-map.csv`：知識ID、仮の配置先、教えるべき観点、参考資料の対応。
- `past-exam-inventory.csv`：私有Driveにある過去問5年度のファイル構成のみ記録。**非公開のDrive URL・ファイルIDを掲載しない。**
- `past-exam-mapping-template.csv`：選択肢単位の分析に使用するテンプレート（内容はまだ未入力）。
- `question-coding-guide.md`：試験問題を細目に対応させる方法。
- `coverage-report.md`：既知のカバー状況、未実施事項、判定条件。

## 作業順

1. **資料マスター**：公式出題範囲→法令・告示→統計→技術資料。改正・版を確認。
2. **知識候補**：原因・制度・対策・測定がつながる粒度まで概念を抽出。候補は `candidate`。
3. **過去問突合**：R03–R07の200問を選択肢レベルに分解して抽出・検証。
4. **目次v3の確定**：重複解説の配置、重要度、本文の深さを調整。
5. **本文・演習**：「超速マスター＋α」の解説、重要な因果の連結、5択問題と解説。

## 注意

`verified-index` は資料の存在と用途を確認済み、`verified-content` は一部の本文・表を確認済み、`index-only` は本文の正式な版が未確認であることを指す。どれも「全文を法的・科学的に監修した」という意味ではない。

既存のWebアプリ（前のPR）は初期試作として残すが、本フェーズでは教材本文の増刷を優先しない。
