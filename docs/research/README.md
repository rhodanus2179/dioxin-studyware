# 過去問：第1次設問索引と選択肢索引

> **現在の教材構成**：[正式目次v3・13章65節](../outline/outline-v3.md)を2026-10-10採択。研究用の過去問／知識項目の節参照は仮の教材分類で、選択肢単位の内容監査が完了したことを意味しません。

対象：ユーザー提供の令和3～7年度（2021～2025年度）の**ダイオキシン類概論・特論のPDF10本**。公式出題数は概論15×5=75問、特論25×5=125問。

## 実施したこと（第1パス）

- 各PDFから `問1...問15/25` を抽出し、計**200問の設問番号**を照合。
- 各設問につき5選択肢の識別子（`-C1`～`-C5`）を生成し、**1000行の選択肢インデックス**を作成。
- 設問冒頭の問題文・キーワードから**主要章・節の仮の振分け**を実施し、該当節の知識IDを候補として記録。
- 図・下線・計算・選択肢の抽出乱れについてフラグを作成。
- 主題を見て既存の知識マップに追加/詳細化した方がよさそうな論点を**候補**として列挙。

## 未実施・絶対に誤解してはいけないこと

- **1000選択肢の主張の意味・正誤理由は、まだ検証していない。** CSVの選択肢行は追跡用IDであり「対応済み」ではない。
- `candidate_knowledge_ids` は**同じ節の知識IDを仮付けしたもの**で、設問内容が全候補ノードに一致するという意味ではない。
- **公式解答表の正解位置と各問の突合は未実施**。表の列位置はPDFのテキスト抽出で崩れるため、視覚的に確認した後に追加する。
- **図や下線**は本文の文字起こしだけでは欠落する場合がある。必ずPDFの元ページを人が確認する。
- 学習サイトに公式問題文・選択肢本文をそのまま転載しない。公開リポジトリには問題ID、独自の要約、論点・管理フラグのみを掲載。
- 統計問題は**その年度の問題に示された調査対象年**を記録する必要がある。原典値の年次差を最新版で上書きしない。
