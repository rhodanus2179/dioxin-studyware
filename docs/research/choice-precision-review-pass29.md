# 第29パス：原題・適用時点法令・規格・物性の根拠監査（2026-10-10）

本作業は第28パスで意味的に再配置した23選択肢について、**法令の出題年度適用版、公開複製問題の表記、独立の公的測定資料、PCB個別異性体の物性表**を確認したもの。分類・正答・掲載可否の3つのステータスを分離した。

## 再確認による進展

1. **R03-G-Q05-C5（2021）**：e-Govの**2021年8月1日施行版**の公害防止組織整備法施行令第5条の3がダイ特法大気1～4号、水質1～14号を引用することを確認（V29-01）。フロン破壊（水質17号）は対象に含まれない。元の法体系の差異は確認できたがJEMAI配布問題PDFのバイト一致は未確認。
2. **R06-G-Q05-C5（2024）**：**2024年9月18日時点**の同条（V29-02）でも同じ号指定。公開複製PDF印刷6頁・PDF index4の**原題模写ページ画像を直接確認**し、選択肢⑤が火床面積0.5m²以上の廃棄物焼却炉と記載することを確認した（V29-03）。大気第5号を組織法の指定に含めないという理由を年度別に確認し、**「規模の下限が違うだけ」という旧草稿を修正**。
3. **R03-G-Q13-C2～C5**：公開複製PDFのテキストと別の独自解説HTML（V29-04）を比較。設問には**『多い順』**、各選択肢には**＜**が使われる。正答①の表示順は左→右で**1＜3＜4＜5**で、最大は右端にある。本文では**降順** `PeCBs(5)＞HxCDFs(4)＞HxCDDs(3)＞HpCBs(1)` と **問題選択肢中の昇順記号表記**を区別して説明する。**PDFテキスト抽出は記号を数字1に崩しており、公開複製のページ画像レンダリングにも失敗したため、原題の視覚検証完了とは言わない**。
4. **R03-A-Q05-C1～C5**：公開複製PDFの計算条件（入口4・出口0.2 ng-TEQ/m³N、SV1500h⁻¹、触媒体積2m³、流量表示m³N/h）を照合。計算で分解率95％・流量3,000m³N/hとなる。**流量の標準状態単位を省略しない**。
5. **R05-A-Q24-C3/C5（ブランク試験）**：公開複製の選択肢③「毎回必ず」、⑤「実施時は3試料以上で平均」の表記をテキストで照合（V29-06）。環境省**2008年・環境大気**測定マニュアル3.5に、汚染リスクによる必須実施と、対策を確認できれば毎回必須でない条件・実施時3試料以上が示される（V29-08）。ただし出題は**排ガス**の規格**JIS K 0311:2020**であり、**正式JIS正本は今回も未閲覧**（V29-09）。他媒体・古い版の文書を法的な同一根拠として流用しない。
6. **R04-G-Q11-C2/C3（コプラナーPCB）**：従来のIARC同族体物性表の一般値だけを用いて試験のコプラナーPCBを判定するのは不適切。WHO IPCS CICAD 55（2003）Table 2ではPCB-77の25℃蒸気圧は**4.4×10⁻⁷ mmHg ≈ 5.87×10⁻⁵ Pa**、PCB-105は**6.531×10⁻⁶ mmHg ≈ 8.71×10⁻⁴ Pa**。**異性体ごとに大きく異なる**ため、コプラナー全体に一つの蒸気圧範囲を確定するには対象異性体と原表の突合がなお必要（V29-07）。以前の「値を高く見積もった」との説明は、同族体の表だけで証明済みとはしない。

## 検証状態の厳密な境界

- **年度別の法律条文**は上記2021年・2024年の指定範囲まで一次照合済み。
- **公開複製問題**は原JEMAI配布PDFと同一か未確認。R06問5の頁は実画像を直接見たが、R03問13・R03特論問5・R05特論問24はPDF抽出文字ないし公開HTMLでの判断であり「画像確認済み」とはしない。
- **JIS K 0311:2020の正本**の確認は**未達**。正式JISCの検索・閲覧ルートは確認済みだが、ログインまたは利用条件を満たす閲覧が必要（V29-09）。
- **独立した掲載前HOLD175選択肢は今回も変更しない**。23件の初期意味的分類保留が0ということは、内容の独立検証完了を意味しない。
