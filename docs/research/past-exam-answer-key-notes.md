# 公式正解表の科目・列対応

令和3～7年度について、ダイオキシン類概論75問・特論125問の正答を、年度別の公式正解表から取り出した。

正解表は18科目が横並び。各科目の問題数を超えるとその列が空白となるため、残存列の位置を計算して読む。ダイオキシン類概論は科目14（15問）、特論は科目15（25問）。

- 問1～10は18列。
- 問11～15は11列。この範囲でダイオキシン類概論・特論はそれぞれ左から8・9番目。
- 問16～20は6列。特論は左から4番目。
- 問21～25は4列。特論は左から4番目。
- R03の問20やR05の問12・13には他科目の特殊解答（複数正答等）があるため、数値変換前に文字列として列数を照合した。ダイオキシン類区分には該当しない。
- 令和7年度は公開原本の正解表を画面でも確認した。令和3～6年度は列数・設問数の整合検証による取り出しであり、全セルの画像上のダブルチェックは未完了。
- 正答位置の照合は、各選択肢の法令・技術的説明の裏付けや選択肢ごとの知識マッピングを意味しない。

出典：JEMAI公表の年度別「正解」PDF。https://www.jemai.or.jp/polconman/examination/past.html
