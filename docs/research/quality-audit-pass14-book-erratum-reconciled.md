# 第14パス：R05概論問12の「正解とヒント」再録図誤植と国家試験の原題を照合（2026-10-10）

## 調査の結論
**2023年度の国家試験問題自体は誤っていない。** 2025年9月10日付の訂正対象は**出版社が刊行した過去問解説書『正解とヒント ダイオキシン類関係 2020～2024年度』R05-69頁の問12再録図**である。試験紙面（AE-14印刷10頁）と、出版社正誤表の正図は一致する。

2026-10-10、ユーザーが正誤表のPDFを添付。PDFの1ページ目を画像としてレンダリングして、**「誤（旧）」の図と「正（新）」の図そのもの**を視認。さらにユーザー提供の2023年度試験問題頁の画像（印刷10頁、AE-14印刷頁）に描かれた5構造式と比較した。

| 視認対象 | 問12の上段右端のPCB：右側環の外側右端 | 何を意味するか |
|---|---|---|
| 2023年国家試験の問題紙面（AE-14印刷10頁） | **Clあり** | 国家試験の試験問題には本来の正しい構造式 |
| 2020～2024年度『正解とヒント』書籍の誤図（2025年正誤表に掲載） | **Clなし** | 書籍再録時の塩素1つ脱落 |
| 同書の正図（2025年正誤表に掲載） | **Clあり**（赤丸で指示） | 書籍側で誤植を修正し国家試験の構造式に一致 |

**出版社の書籍の正誤表を「公式試験問題そのものの訂正」や「公式正答の変更」とみなしてはならない。** 第13パスのP0保留は「出版社図の未視認」に基づくもので、今回の図比較により解消。

## 正答・分子構造への影響

2023年原題および出版社の正図の5構造式にはWHO-TEF(2006)対象が4種類。上段中央はPCB #118、上段右はPCB #105、下段左はPCB #81、下段中央はPCB #189。上段左はWHO対象12種に含まれない。したがって**正答④（4種類）は従前どおりであり、変更しない**。

書籍の旧図では、上段右端のPCBの右側ベンゼン環の外側右端Clを欠くため、上段右の構造自体が原題と異なって見える。これが書籍で出題を復習した読者を混乱させる原因になる。
