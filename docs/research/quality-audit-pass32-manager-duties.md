# 第32パス：R07概論問5「公害防止管理者の管理する業務」を独立概念に再配置（2026-10-10）

## 対象と修正した根本原因

2025年度ダイオキシン類概論・問5の5選択肢は、**特定工場における公害防止組織の整備に関する法律に基づくダイオキシン類関係公害防止管理者の管理する技術的事項**を問う。これをダイオキシン類対策特別措置法の「設置・変更等の届出」（DX-G01-015）へ割り当てた旧マッピングは誤りだった。

- 新知識ID：**DX-G01-024**「公害防止管理者の管理する技術的事項（発生施設の点検と処理施設の補修）」
- 正式65節・185項は維持し、**1.5.3「公害防止管理者の業務と事業者測定・公表」**に新知識を追加した。
- 5選択肢 R07-G-Q05-C1～C5を新ID／項1.5.3に移動。事業者自身の排出測定義務と公害防止管理者の業務を混同しない。
- 知識ID総数 **225→226**、代表概念 **217→218**、未リンク知識 **118のまま**。問題別の旧索引を一括改稿していないので設問単位の旧知識リンク96件は維持、別レイヤーとして取り扱う。

## 一次資料・原題との照合

- JEMAI公式2025年度問題PDFの印刷6頁（PDF index 4）に問5の5つの候補と「該当しないもの」の設問が掲載：https://www.jemai.or.jp/polconman/examination/dd4ht300000005fn-att/R07_14.pdf
- 根拠法令は組織整備法4条1項7号 https://laws.e-gov.go.jp/law/346AC0000000107 と、組織整備法施行規則6条7項 https://laws.e-gov.go.jp/law/346M50010D40003/20190401_431M60001F40001 。
- 省令7項の各号：**燃料・原材料の検査**、**発生施設の点検**、**排出ガス・排出水処理施設の操作・点検・補修**、**排出量の測定・記録**、**測定機器の点検・補修**、緊急時の措置等を列挙する。
- したがってC2の「発生施設そのものの補修」は、当該規定の**管理業務として列挙されていない**。これは補修自体が違法・禁止ということではない。
- C1・C3・C4・C5は列挙された業務に対応する。公式正答番号は従来のC2を変更しない。

**監査限界**：公開法令の2019-04-01適用条文で技術的事項一覧を確認し、現在公開の法令及び2025年度問題の本文に照合。**試験で準拠すべき2025年4月1日時点の統合条文と2019版の逐語一致について、独立した確定検証は未了**。法令の最終適用版確認と解説の公開前校閲は別ゲート。
