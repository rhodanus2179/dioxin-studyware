# 第6パス：R05概論問12の5化合物とWHO-TEF、JIS正本へのアクセス調査（2026-10-09）

## 対象と厳密な結論
- 国家試験2023年度ダイオキシン類概論問12は、問題原図に描かれた5化合物のうち**TEF付与対象の個数**を選ぶ。正答表は「4種類」（選択肢④）。
- [2023年の受験者による解答記録](https://www.sotetsu92101.com/entry/2023/10/01/143220)と[2024年の独立解説](https://pierre-usagi.com/kougai-r5-dxn-gairon-12/)は、図の5構造について**同じ化合物名を同じ配置で列挙**している。
- 化合物名が正しいという**条件付き**なら、[環境省のWHO-TEF(2006)一覧（平成20年度環境調査報告、PDF p21・印刷p19）](https://www.env.go.jp/air/report/h21-03/full.pdf)で、#81、#105、#118、#189が指定対象であると一次資料で確認できる。左上の2,3,3′,5,5′-PeCBは、指定される12のDL-PCB同族体に含まれない。
- 以上から、**二次資料の異性体名を前提にした4/5という毒性評価の照合は支持される**。しかし、原題図やJEMAI書籍正誤表の旧図・新図を直接見ていないので、**国家試験の構造式を確定したとはしない**。

## 三点画像比較の実施可否
1. JEMAI[2025-09-10付『正解とヒント』正誤表](https://www.e-jemai.jp/purchase/pdf/dd9c29e44bcac9d799c422dea534832b0f106c64.pdf)のPDF本文で、R05-69問12の図訂正があることは確認。しかし画像のWebスクリーンショットはキャッシュミスで失敗し、他の取得経路でもPDF原本はダウンロードできず、旧図・新図の具体的差異は特定できなかった。
2. [転載されたR05概論問題PDF](https://pierre-usagi.com/wp-content/uploads/2025/01/R05_14.pdf)も画像スクリーンショットがキャッシュミス。ユーザーDrive保存の同題PDFは文字抽出で問12の内容を再確認したが、5構造式の画像は抽出できず、化合物置換位置を直接確認できなかった。
3. よって「元試験図／出版社の誤図／正図」の**三点視認は未完了**。これらの画像を入手するまでR05-G-Q12-C1〜C5をP0保留のままとする。**書籍に訂正図がある＝国家試験の正答番号が訂正された、ではない**。

## JIS K 0311:2020正式規格の確認ルート
- [日本産業標準調査会の公式説明](https://www.jisc.go.jp/jis-act/reading.html)により、**JIS検索 → 規格番号 K0311 → JIS規格詳細 → 画像PDFの閲覧**ができることを確認。
- [JISC利用規約](https://www.jisc.go.jp/site/)では、**2020-12-02以降は閲覧者登録と規約同意が必要**。一般に規格本文は印刷・ダウンロード不可で、引用・転載にも制約がある。本パスではログイン付きPDF本文を表示できていないため、**JIS K 0311:2020の規格正本監査は未了**。
- 先のR06特論問19（ロックマス方式）は非公式転載の7.2.1.1／7.2.1.2／7.2.2.2に基づく暫定照合。登録後に対応箇所を正本で照合できるまでは暫定のまま。
